# MatrixDiagonalsComparator

## Назначение

Программа предназначена для сравнения сумм элементов главной и побочной диагоналей квадратной вещественной матрицы размерности n.

## Требования к окружению

- Python версии 3.8 или новее.
- Windows 10/11, Linux или macOS.
- Только стандартная библиотека Python, без сторонних зависимостей.

## Запуск

Откройте терминал в папке проекта и запустите сервер:

```bash
python src/server.py
```

Оставьте сервер работающим. В другом окне терминала, в той же папке,
запустите клиент:

```bash
python src/main.py
```

Введите размер матрицы и её элементы по одному. Программа выведет
матрицу, суммы диагоналей и результат сравнения. Для остановки сервера
нажмите Ctrl+C в его окне.

## Стратегия ветвления

используется простая схема с двумя ветками — main и develop;
main содержит проверенную версию проекта;
изменения готовятся в develop, проверяются и объединяются с main;
эта схема подходит небольшому учебному проекту, потому что понятна и позволяет отдельно готовить изменения.
