# Архитектура MatrixDiagonalsComparator

## Назначение проекта

Проект предназначен для сравнения сумм элементов главной и побочной диагоналей квадратной вещественной матрицы размерности `n`.

## Текущее состояние

Подготовлены техническое задание, описание алгоритма, документация проекта, конфигурация CI и шаблоны GitHub. Исходный код программы и автоматические тесты пока не реализованы. Ниже описана планируемая архитектура программы.

## Планируемые части программы

Программа будет представлять собой один скрипт Python с разделением обязанностей между функциями.

| Часть | Ответственность |
| --- | --- |
| Ввод и проверка данных | Получить положительное целое число `n`, затем прочитать `n` строк по `n` вещественных чисел. При ошибке вывести понятное сообщение и повторить ввод. |
| Вычисление сумм | Вычислить суммы главной и побочной диагоналей за один проход по индексам. |
| Сравнение | Сравнить суммы с учётом погрешности `EPS = 1e-7`. |
| Вывод | Показать исходную матрицу, обе суммы и текстовый результат сравнения. |
| Управление выполнением | Последовательно вызвать части программы и завершить расчёт. |

Разделение позволит проверять вычисления отдельно от ввода с клавиатуры и вывода на экран.

## Представление данных и алгоритм

Матрица будет храниться как список из `n` списков чисел типа `float`. Индексы строк и столбцов начинаются с нуля.

- Главная диагональ: элементы `matrix[i][i]`.
- Побочная диагональ: элементы `matrix[i][n - 1 - i]`.
- Индекс `i` последовательно принимает значения от `0` до `n - 1`.

При нечётном `n` центральный элемент входит в обе суммы, поскольку принадлежит обеим диагоналям.

Если `abs(main_sum - secondary_sum) < EPS`, суммы считаются равными. В остальных случаях определяется, какая сумма больше. Значение погрешности выбирается на основе технического задания и описания алгоритма.

## Последовательность работы

```text
Ввод размера → проверка размера → ввод и проверка матрицы
→ вычисление сумм → сравнение с учётом EPS → вывод результата
```

## Окружение и сложность

По техническому заданию программа должна работать на Python 3.8 или новее и использовать стандартную библиотеку. Предусмотрен запуск в командной строке Windows, Linux или macOS. База данных и сетевые подключения для расчёта не требуются.

Вычисление двух сумм занимает `O(n)` времени. Хранение всей матрицы требует `O(n²)` памяти. Ввод и вывод всех элементов занимают `O(n²)` времени.

## Автоматические проверки

Файл `.github/workflows/ci.yml` запускает CI при отправке изменений в `main` и `develop`, а также для Pull Request в эти ветки.

CI устанавливает инструменты проверки и проверяет Markdown в `README.md` и `docs`. Если появятся файлы Python, будет выполняться `flake8`. Если появятся тесты `unittest` с именами `test_*.py` в `tests`, будет выполняться их запуск. До появления соответствующих файлов эти два этапа пропускаются.
