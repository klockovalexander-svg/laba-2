# Ревью кода интеграции

## Цель проверки

Проверить читаемость кода, взаимодействие модулей и обработку
ошибок при передаче и вычислении данных.

## Проверенные файлы

- `src/main.py` — клиентская часть;
- `src/server.py` — серверная часть;
- `src/matrix.py` — вычисление сумм диагоналей;
- файлы автоматических тестов в каталоге `tests`.

## Проверка стиля

Для проверки Python-кода использован линтер `flake8`.
На момент проверки замечаний не обнаружено.

## Результаты ревью

1. Модули имеют отдельные назначения: ввод и вывод, обработка
   HTTP-запросов и вычисление сумм диагоналей.
2. Клиент сообщает об ошибках ввода, недоступности сервера,
   превышении времени ожидания и конфликте версий.
3. Сервер проверяет формат запроса, версию, размер и форму
   матрицы, а также тип её элементов.
4. При сбое вычислительной функции сервер возвращает код 503.
5. Автоматические тесты проверяют обычный запрос и ряд ошибок.
   При последнем локальном запуске прошли 14 тестов.

## Замечания и ограничения

- Автоматические тесты пока не покрывают все строки программы.
- Успешный ответ сервера передаётся в JSON, а ответы об ошибках,
  сформированные методом `send_error()`, возвращаются в HTML.
- При ошибке вычислительной функции сервер сообщает о её
  недоступности. Подробности ошибки записываются в журнал сервера.
- При отсутствии файла вычислительного модуля сервер запускается,
  но возвращает HTTP 503 для запросов вычисления; событие пишется в журнал.
