# Тестирование ЛР №4

Вариант 5. Объект тестирования - MatrixDiagonalsComparator. Основной метод - анализ причинно-следственных связей. Автоматические тесты написаны на `unittest`. Целевое покрытие - не менее 75%.

## План и сценарии

1. Проверить вычисление обеих сумм и три исхода сравнения.
2. Проверить обмен по HTTP и обработку ошибочных запросов.
3. Запустить полный набор автоматических тестов и отдельно две регрессионные проверки.
4. Измерить покрытие всех исходных модулей с учётом ветвей и провести инспекцию кода.

| Проверка | Вход | Ожидалось | Получено |
| --- | --- | --- | --- |
| Главная диагональ больше | `[[4, 1], [2, 3]]` | Суммы 7 и 3, главная больше | Суммы 7 и 3, главная больше |
| Побочная диагональ больше | `[[2, 4], [3, 1]]` | Суммы 3 и 7, побочная больше | Суммы 3 и 7, побочная больше |
| Диагонали равны | Матрица 3×3 с числами от 1 до 9 | Суммы 15 и 15, равенство | Суммы 15 и 15, равенство |
| Поддерживаемая версия | `version: 1` и корректная матрица | HTTP 200 | HTTP 200 |
| Неподдерживаемая версия | `version: 2` и корректная матрица | HTTP 409 | HTTP 409 |
| Версия в виде строки | `version: "1"` и корректная матрица | HTTP 409 | HTTP 409 |
| Вещественная версия | `version: 1.0` и корректная матрица | HTTP 409 | HTTP 409 |
| Отсутствует матрица | `{"version": 1}` | HTTP 400 | HTTP 400, Invalid JSON or missing matrix |
| Неквадратная матрица | `{"version": 1, "matrix": [[1, 2]]}` | HTTP 400 | HTTP 400, Matrix must be square |

Все девять ручных проверок пройдены. Автоматический набор дополнительно проверяет тайм-аут клиента и ответ HTTP 503 при недоступности вычислительного модуля.
