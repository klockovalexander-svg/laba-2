## Замечания и рекомендации

1. Версии flake8 и pymarkdownlnt при установке не закреплены. Рекомендуется указать конкретные версии, чтобы результаты проверок были воспроизводимыми.
2. CI использует Python 3.12, а техническое задание предусматривает Python 3.8 или новее. После реализации программы необходимо проверить совместимость с заявленными версиями.
3. После появления исходного кода следует проверить обработку ошибочного ввода, индексы диагоналей и сравнение сумм с погрешностью.
4. После реализации тестов необходимо запустить их локально и в GitHub Actions, записав фактические результаты.
