# MatrixDiagonalsComparator

Учебный проект по дисциплине «Инструментальные средства разработки программного обеспечения». Программа вычисляет суммы главной и побочной диагоналей квадратной вещественной матрицы и сравнивает их.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `src/main.py` | Консольный ввод, отправка матрицы на сервер и вывод результата сравнения |
| `src/server.py` | Обработка HTTP-запросов, проверка входных данных и возврат ответа в JSON |
| `src/matrix.py` | Вычисление сумм главной и побочной диагоналей |
| `tests/` | Модульные, интеграционные и регрессионные проверки |
| `docs/` | Описание алгоритма, архитектуры, интеграции и тестирования |
| `.github/workflows/` | Автоматические проверки GitHub Actions |

## Запуск

Для запуска используется стандартная библиотека Python. В GitHub Actions проект проверяется на Python 3.12.

Откройте терминал в корне проекта и запустите сервер:

```bash
python src/server.py
```

Оставьте сервер запущенным. Во втором терминале из той же папки запустите клиент:

```bash
python src/main.py
```

Введите размер матрицы и её элементы по одному, построчно. Клиент выведет матрицу, обе суммы и результат сравнения. Сервер можно остановить сочетанием `Ctrl+C`.

## Тестирование ЛР №4

Вариант 5. Основной метод - анализ причинно-следственных связей. Автоматические тесты выполняются через `unittest`. Целевое покрытие - не менее 75%.

Полный прогон и отдельный запуск регрессионных проверок:

```bash
python -m unittest discover -s tests -v
python -m unittest discover -s tests -k regression -v
```

Измерение покрытия с учётом ветвлений и проверка стиля:

```bash
python -m pip install coverage flake8
python -m coverage run --branch --source=src -m unittest discover -s tests
python -m coverage report -m --fail-under=75
python -m flake8 src tests --count
```
