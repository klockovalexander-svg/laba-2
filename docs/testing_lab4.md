# План тестирования ЛР №4

Вариант 5. Основной метод - анализ причинно-следственных связей.
Проверяются вычислительный модуль, консольный клиент и HTTP-сервер.

- Рассчитать вручную суммы для контрольных матриц.
- Проверить JSON-запросы с версиями 1, 2, "1" и 1.0 и с некорректной формой матрицы.
- Запустить модульные и интеграционные проверки через unittest.
- Отдельно запустить проверки сравнения с фильтром regression.
- Выполнить flake8 и измерить покрытие операторов и ветвей через coverage.

Локально пройдено 18 тестов. Общий показатель покрытия - 82%.
Детализация приведена в testing_metrics.md.
