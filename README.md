# # MatrixDiagonalsComparator — основная версия

## Назначение

Программа предназначена для сравнения сумм элементов главной и побочной диагоналей квадратной вещественной матрицы размерности n.

## Требования к окружению

- Python версии 3.8 или новее.
- Windows 10/11, Linux или macOS.
- Только стандартная библиотека Python, без сторонних зависимостей.

## Запуск

Инструкция предварительная. После создания файла `matrix_diagonals_comparator.py` в папке `src` необходимо открыть терминал в основной папке проекта и выполнить:

```bash
python src/matrix_diagonals_comparator.py
```

Затем ввести размер матрицы и её элементы построчно. Программа должна вывести матрицу, суммы диагоналей и результат сравнения.
