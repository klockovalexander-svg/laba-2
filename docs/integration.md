# Документация интеграции

## 1. Назначение

Проект MatrixDiagonalsComparator сравнивает суммы элементов
главной и побочной диагоналей квадратной матрицы.

Программа состоит из трёх модулей:

- `main.py` — ввод матрицы, отправка запроса и вывод результата;
- `server.py` — приём запроса и отправка ответа;
- `matrix.py` — вычисление сумм диагоналей.

## 2. Взаимодействие модулей

1. Пользователь вводит размер и элементы матрицы в `main.py`.
2. `main.py` отправляет матрицу серверу по HTTP в формате JSON.
3. `server.py` получает матрицу и передаёт её функции
   `calculate_diagonals()` из модуля `matrix.py`.
4. Функция возвращает серверу две суммы.
5. Сервер отправляет суммы клиенту в формате JSON.
6. `main.py` сравнивает суммы и выводит результат.

## 3. Пример запроса и ответа

Адрес запроса: `http://127.0.0.1:8000/compare`

Метод запроса: `POST`

Пример отправляемой матрицы:

```json
{"matrix": [[2, 4], [3, 1]]}
```

Ответ сервера:

```json
{"main_sum": 3, "side_sum": 7}
```

`main_sum` — сумма главной диагонали, `side_sum` — сумма
побочной диагонали.

## 4. Схема потока данных

```text
Пользователь
    │ вводит матрицу
    ▼
main.py
    │ отправляет матрицу в JSON по HTTP
    ▼
server.py
    │ передаёт матрицу в функцию calculate_diagonals()
    ▼
matrix.py
    │ возвращает две суммы
    ▼
server.py
    │ отправляет суммы в JSON по HTTP
    ▼
main.py
    │ сравнивает суммы и выводит результат
    ▼
Пользователь
```

## 5. Протокол и формат обмена

Для передачи данных между клиентом и сервером используется HTTP.
Клиент отправляет POST-запрос с матрицей.

Данные запроса и ответа представлены в формате JSON. Матрица
передаётся как массив строк, а суммы диагоналей — как числа.

## 6. Сопоставление данных

| Данные | В main.py | В JSON | В server.py и matrix.py |
|---|---|---|---|
| Матрица | Список `matrix` | Поле `matrix`: массив строк | Сервер получает `matrix` и передаёт в функцию |
| Сумма главной диагонали | Переменная `main_sum` | Поле `main_sum`: число | Функция возвращает первую сумму |
| Сумма побочной диагонали | Переменная `sade_sum` | Поле `side_sum`: число | Функция возвращает вторую сумму |
